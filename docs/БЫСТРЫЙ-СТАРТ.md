# Быстрый старт

Три команды и пятнадцать минут. Если вы умеете открыть терминал и вставить
строку — этого достаточно.

Разжёванная версия с объяснением каждого шага:
[УСТАНОВКА-ПО-ШАГАМ.md](УСТАНОВКА-ПО-ШАГАМ.md)

---

## Что понадобится

| Что | Где взять | Нюанс |
|---|---|---|
| **VPS** с Ubuntu или Debian | любой провайдер | от 1 ГБ памяти, от 3 ₽/мес |
| **SSH-доступ** к нему | придёт от провайдера | обычно логин, пароль и адрес |
| **Python 3.8+** | [python.org](https://python.org) | на Windows есть вместе с установщиком |
| **Блокнот** | — | — |

**Не нужно:** домен, сертификат, опыт в сетях, умение читать логи.

---

## Шаг 1. Получить репозиторий

Откройте терминал.

**Windows** — нажмите `Win + R`, напишите `powershell`, Enter.
**macOS или Linux** — откройте «Терминал» из списка программ.

Вставьте одну строку и нажмите Enter:

```bash
git clone https://github.com/petrles444-source/SORA.git
cd SORA/tools
```

**Если ругается, что `git` не найден** — поставьте его:
[git-scm.com/downloads](https://git-scm.com/downloads). На Windows при
установке оставьте галочку «Git from the command line».

**Если `git clone` ругается на сеть** — скачайте ZIP-файл кнопкой
`Code → Download ZIP`, распакуйте и откройте в терминале папку
`SORA/tools` внутри распакованного архива.

---

## Шаг 2. Создать ключи

Ключ — это файл, который пускает конкретное устройство в ваш VPN.
Один ключ на одно устройство. Свою фамилию впишите свою.

```bash
python sora_keys.py init
```

Это создаст файл-реестр. В нём будет записано, кому какой ключ выдан.

Теперь выдайте ключи:

```bash
python sora_keys.py add ivan --note "телефон"
python sora_keys.py add olga --note "ноутбук"
```

Замените `ivan` и `olga` на любые имена — они просто подписи.
На каждое устройство — отдельный ключ.

Посмотреть, кто есть:

```bash
python sora_keys.py list
```

---

## Шаг 3. Получить файл для сервера

```bash
python sora_keys.py server --out ../server/server.conf
```

Появится файл `server/server.conf`. Его надо передать на сервер —
следующий шаг.

**Проверить, что всё в порядке:**

```bash
python sora_doctor.py
```

Если написано «всё в порядке» — идём дальше. Если нет — он сам скажет,
что делать, и даст готовую строку.

---

## Шаг 4. Установить на сервер

Подключитесь к серверу. Адрес, логин и пароль даст провайдер.

```bash
ssh root@ваш-адрес
```

После входа вы окажетесь на сервере. Проверьте, что это он:

```bash
cat /etc/os-release | head -2
uname -m
```

Теперь скопируйте на сервер папку `server` и запустите установку.
Самое простое — вставить одну команду, которая всё скачает и поставит:

```bash
curl -sSL https://raw.githubusercontent.com/petrles444-source/SORA/main/server/install_sora.sh | bash
```

Установщик спросит несколько раз. На каждый вопрос отвечайте `y`.

Он:

- поставит `amneziawg-go`
- создаст туннель
- откроет нужные порты
- поставит учёт трафика и лимиты
- проверит, что всё работает

## Шаг 5. Проверить, что работает

```bash
sora-selftest.sh
```

Ожидаемый вид:

```
[ OK ]  служба amneziawg-go запущена
[ OK ]  туннель поднят, интерфейс awg0 есть
[ OK ]  ключи на месте
[ OK ]  учёт трафика считает
```

Если где-то `[ ОШИБКА ]` — покажите вывод ИИ по
[СПРОСИ-ИИ.md](СПРОСИ-ИИ.md).

## Шаг 6. Подключить телефон

Установите приложение **AmneziaVPN** из App Store или Google Play.

1. Откройте его.
2. Скопируйте файл конфига на телефон.
3. В приложении: **Настройки → Добавить конфиг** → выберите файл.
4. Нажмите **Подключиться**.

Файл конфига лежит в папке `client/` рядом с `server/`.

**Проверить, что подключилось.** Откройте с телефона сайт
`https://ifconfig.me` — он покажет ваш адрес. Он должен отличаться от
домашнего.

## Готово

Теперь у каждого вашего устройства — свой адрес, свой ключ и свой лимит
трафика.

**Посмотреть, кто сколько качает:**

```bash
sora_traffic.py report
```

**Отключить ключ, который больше не нужен:**

```bash
python sora_keys.py revoke ivan
```

## Если пошло не так

| Симптом | Что делать |
|---|---|
| `python` не найден | поставьте Python с [python.org](https://python.org) |
| `git` не найден | поставьте Git с [git-scm.com](https://git-scm.com/downloads) |
| `ModuleNotFoundError` | `pip install -r ../requirements.txt` |
| VPN не подключается | [docs/СПРОСИ-ИИ.md](СПРОСИ-ИИ.md) |
| Сайт не открывается | см. «Настройте исключения» ниже |

### Настройте исключения — важно

Через ключ российские сайты открываются медленнее или не открываются
вообще: трафик идёт за границу и обратно. Чтобы такого не было,
исключите российские адреса из туннеля.

1. В AmneziaVPN: **Настройки → Параметры маршрутизации → Разделить трафик**
2. Отметьте «Исключить заблокированные адреса» и «Исключить локальные
   адреса»
3. В поле исключений впишите:

```
geoip:RU
geoip:SU
```

**После этого через туннель пойдёт только то, что без него не
открывается**, а российские сайты — напрямую. Месячный лимит перестанет
уходить за день.

Банк и Госуслуги после этого работают как обычно.
