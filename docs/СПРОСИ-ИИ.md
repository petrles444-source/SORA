# Не понимаешь — спроси ИИ

Не нужно разбираться в сетях, туннелях и правилах брандмауэра.
Откройте ИИ, вставьте готовый запрос и вывод команды, которая не
сработала.

**Это работает лучше поиска в интернете,** потому что ИИ смотрит на
вашу конкретную ошибку, а не на общую статью про то, как настроить VPN.

---

## Каким ИИ пользоваться

Подойдёт любой, у которого есть доступ в интернет:

| Сервис | Когда выбирать |
|---|---|
| **ChatGPT** (OpenAI) | самый универсальный, есть бесплатный |
| **Claude** (Anthropic) | хорошо объясняет по шагам |
| **Gemini** (Google) | если вы уже работаете с экосистемой Google |
| **Copilot** (Microsoft) | встроен в Windows |
| **Любая модель локально** | Ollama, LM Studio — если не хотите отправлять вывод в интернет |

## Запрос 1. Помоги установить

Когда вы ещё не начали. Скопируйте целиком и вставьте, заменив слова в
скобках.

```
Я никогда не настраивал VPN на сервере. Объясни с самого начала.

Мой сервер: Ubuntu 22.04 или Debian 12, к нему есть SSH-доступ root.
Что уже есть в проекте: скрипт install_sora.sh, который ставит
AmneziaWG, создаёт туннель, открывает порты и включает учёт трафика.

Задача: подробная пошаговая инструкция, которую я смогу выполнить
без вопросов. Для каждого шага:
1. Что делать — точная команда, которую вставить.
2. Что должно получиться — как выглядит правильный вывод.
3. Что делать, если вывод не такой — что значит ошибка и как её исправить.
4. Что проверить после шага, чтобы убедиться, что шаг удался.

Не пропускай шаги и не пиши «аналогично». Если что-то может сломаться,
скажи заранее, до того как человек это сделает.

Мой уровень: новичок. Терминал открыть умею, команды копировать умею.
Сети не знаю.
```

## Запрос 2. Что-то не работает

Когда уже стоит и не работает. **Скопируйте запрос, вставьте вывод
команды и говорите, что ожидали.**

```
Не работает VPN на моём сервере. Помоги разобраться.

Что делаю: подключаюсь через туннель на телефоне.

Что происходит: [ОПИСАНИЕ ПРОБЛЕМЫ — например "сайты открываются,
но медленно, а Telegram не подключается совсем"]

Ожидаю: [ЧТО ДОЛЖНО БЫТЬ]

Вот вывод команд с сервера:

[ВСТАВЬТЕ ВЫВОД СЮДА, ЦЕЛИКОМ]

Отвечай по шагам:
1. Что означает каждая строка вывода.
2. Какая строка говорит о проблеме, а какая — просто инф��рмация.
3. Что делать, чтобы починить, — точные команды.
4. Как проверить, что починилось.

Если вывода недостаточно, скажи какие команды надо выполнить
дополнительно, и объясни зачем каждая.
```

### Какие команды снимать, когда что-то не работает

```bash
systemctl status amneziawg-go
ip addr show awg0
ss -tlnp
sora-selftest.sh
python tools/sora_doctor.py          # на своём компьютере
```

## Запрос 3. Разбор одной ошибки

Когда ИИ ответил, но вы не поняли ответ.

```
Объясни простыми словами, без терминов, что значит этот вывод
и что конкретно делать:

[ВСТАВЬТЕ ВЫВОД]

Мой вопрос: [ЧТО ВЫ НЕ ПОНЯЛИ]

Правила ответа:
- без сокращений и технического жаргона,
- каждый шаг — одна команда, которую можно скопировать,
- объясни, зачем этот шаг нужен,
- если есть риск что-то сломать — предупреди заранее.
```

## Правила, чтобы ИИ не выдумывал

Четыре строчки, которые стоит добавлять к любому запросу. Они экономят
время на выдуманные советы.

```
1. Не выдумывай команды и флаги. Если не знаешь точно — скажи прямо.
2. Если команда может что-то удалить или отключить — предупреди
   заранее, до того как я её выполню.
3. Не меняй то, о чём я не просил. Одна проблема — одно решение.
4. Если для решения нужна информация, которой у тебя нет, —
   спроси, какую команду мне выполнить, чтобы её получить.
```

## Чего ИИ делать не надо

Даже если он предлагает — не делайте без проверки.

| Что предлагают | Почему не надо |
|---|---|
| Отключить `iptables` целиком | останетесь без защиты от взлома |
| Удалить `server.conf` и пересоздать | потеряете все ключи |
| Вписать `0.0.0.0/0` в маршруты | весь трафик пойдёт в туннель, лимит кончится за день |
| `chmod 777` на что бы то ни было | открываете доступ всем |
| Отключить проверку сертификатов | перестаёте видеть подмену |

## Если ИИ не помог

1. `sora-selftest.sh` на сервере — покажите вывод целиком.
2. `python tools/sora_doctor.py` на своём компьютере — там 25 проверок,
   он скажет, что не так, и даст готовую команду.
3. Откройте [Issues](https://github.com/petrles444-source/SORA/issues) —
   приложите вывод и опишите, что делали.

## Хороший вопрос — половина решения

Когда описываете проблему ИИ, ответьте себе на четыре вопроса. Если
хоть один «не знаю» — так и напишите. Честное «не знаю» полезнее
придуманного «вроде работает».

1. Что я делал, по шагам?
2. Что ожидал получить?
3. Что получил на самом деле?
4. Что уже пробовал сделать?

**Приложите вывод целиком.** Обрезанный вывод в половине случаев
бесполезен — ошибка может быть в строке, которую вы не заметили.
